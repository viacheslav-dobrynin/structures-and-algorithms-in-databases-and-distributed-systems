# Алгоритмы и структуры данных в распределенных системах

## О разделе

Раздел посвящён структурам данных и алгоритмам, которые проявляют себя именно в распределённой среде, где нет единого узла, общей памяти и мгновенной связи. Здесь приходится считаться с репликацией ради доступности, с задержками и сетевыми разделениями, а также с тем, что согласованность копий данных достигается не сразу. Структуры данных в таких условиях должны либо сами разрешать конфликты обновлений, либо экономно отвечать на запросы о принадлежности, минимизируя сетевой обмен и память.

Мы рассматриваем два дополняющих друг друга сюжета: бесконфликтные реплицируемые типы данных (CRDT), которые гарантируют сходимость реплик без координации, и вероятностные структуры (фильтр Блума), которые компактно отвечают на вопрос о членстве с контролируемой вероятностью ошибки. Вместе они иллюстрируют, как в распределённых системах ради масштабируемости приходится менять привычные гарантии — точность и строгую согласованность — на доступность и эффективность.

## Предпосылки

Для чтения раздела желательно понимать:

- теорему CAP и компромисс между согласованностью и доступностью;
- итоговую (eventual) согласованность;
- основы репликации данных между узлами;
- хеширование и его применение для распределения данных.

## Темы раздела и порядок чтения

1. [CRDT (бесконфликтные реплицируемые типы данных)](./crdt.mdx) — типы данных, реплики которых сходятся к одному состоянию без координации; центральный механизм согласованности без блокировок в AP-системах.
2. [Фильтр Блума](./probabilistic/bloom-filter.mdx) — вероятностная структура для компактной проверки принадлежности, допускающая ложноположительные ответы; широко применяется для сокращения сетевых и дисковых обращений в распределённых хранилищах.

Порядок ведёт от согласованности и разрешения конфликтов к пространственно-эффективным структурам, поддерживающим работу распределённых хранилищ.
