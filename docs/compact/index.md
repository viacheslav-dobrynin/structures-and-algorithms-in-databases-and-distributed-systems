# Компактные структуры данных

## О разделе

Раздел посвящён компактным и сукцинктным (succinct) структурам данных — представлениям, которые занимают объём, близкий к информационно-теоретической нижней границе, но при этом поддерживают быстрые операции запроса. Обычные структуры данных ради скорости тратят память расточительно: указатели, выравнивание и служебные поля могут многократно превышать объём самих данных. Когда данные не помещаются в оперативную память или дороги в передаче, такая расточительность становится узким местом.

Компактные структуры решают эту проблему, кодируя данные почти оптимально по объёму и опираясь на операции rank/select по битовым векторам, чтобы навигация по сжатому представлению оставалась быстрой. Это особенно ценно для больших графов и текстов, где разница между наивным и сукцинктным представлением определяет, поместится ли структура в память узла. Раздел сейчас служит точкой входа в эту тему с одним материалом и оставляет пространство для расширения.

## Предпосылки

Для чтения раздела желательно понимать:

- битовые операции и работу с битовыми векторами;
- интуицию операций rank и select (подсчёт и поиск k-го установленного бита);
- основные способы представления графов (список смежности, матрица смежности);
- понятие информационно-теоретической нижней границы на объём представления.
