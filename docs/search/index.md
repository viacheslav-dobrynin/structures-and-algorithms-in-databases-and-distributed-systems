# Алгоритмы и структуры данных поиска

## О разделе

Раздел посвящён индексам — структурам данных, которые превращают полный перебор (full scan) в сублинейный поиск. Без индекса ответ на запрос требует просмотра всех записей, и стоимость растёт линейно с объёмом данных; индекс же позволяет находить нужные записи за логарифмическое или почти константное время. В контексте баз данных и распределённых систем индексирование — ключевой механизм, обеспечивающий приемлемую задержку при росте данных.

Мы рассматриваем индексы для разных типов нагрузок: одномерные диапазонные запросы (B-деревья), многомерный пространственный поиск (R-деревья, PostGIS), полнотекстовый поиск (инвертированный индекс), приближённый поиск ближайших соседей в векторных пространствах (HNSW) и проверку целостности данных (деревья Меркла). Каждый класс индексов отвечает на вопрос «как быстро найти?» для своей разновидности данных и запросов.

## Предпосылки

Для комфортного чтения раздела полезно заранее понимать:

- асимптотическую сложность и нотацию «O большое»;
- двоичные деревья поиска (BST) и идею балансировки;
- основы хеширования (хеш-функции, коллизии);
- разницу в стоимости доступа к оперативной памяти и к диску (почему количество обращений к диску важнее количества операций в CPU).

## Темы раздела и порядок чтения

1. [B-деревья](./trees-and-graphs/b-trees.mdx) — базовый дисково-ориентированный индекс для одномерных и диапазонных запросов; задаёт фундамент, на котором строятся индексы реляционных СУБД.
2. [R-дерево](./spatial-indexes/r-tree.mdx) — обобщение идеи B-дерева на многомерные данные через ограничивающие прямоугольники; основа пространственного поиска.
3. [PostGIS](./spatial-indexes/postgis.mdx) — практическое применение пространственного индексирования в PostgreSQL; показывает, как теория R-деревьев работает в реальной СУБД.
4. [Инвертированный индекс](./text-indexes/inverted-index.mdx) — структура для полнотекстового поиска, отображающая термины в списки документов; основа поисковых систем.
5. [HNSW](./vector-indexes-and-quantization/hnsw.mdx) — графовый индекс для приближённого поиска ближайших соседей в векторных пространствах; актуален для семантического поиска и эмбеддингов.
6. [Дерево Меркла](./hashing/merkle-tree.mdx) — хеш-дерево для эффективной проверки целостности и сравнения наборов данных; связывает поиск с верификацией и используется в распределённых системах.

Порядок отражает движение от классических одномерных индексов к многомерным, текстовым и векторным, а затем к хеш-структурам целостности.
